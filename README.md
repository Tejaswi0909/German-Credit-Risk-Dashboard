# German-Credit-Risk-Dashboard

## Project Overview
This project focuses on analyzing German sales and business performance data using Power BI and SQL. The dashboard provides insights into sales trends, customer behavior, revenue performance, and regional analysis to support data-driven business decisions.

## Tools Used
- Power BI
- SQL
- Excel / CSV
- Data Analytics

## Key Insights
- Regional sales performance analysis
- Revenue and profit tracking
- Customer trend analysis
- KPI monitoring and visualization
- Business growth insights

## Dashboard Features
- Interactive dashboard
- Dynamic filters and slicers
- KPI cards
- Sales trend visualization
- Regional performance analysis
- Customer insights

## Files Included
- Power BI Dashboard (.pbix)
- Dataset (.csv)
- SQL Queries (.sql)
- Dashboard Screenshots

## Business Impact
This dashboard helps businesses understand market performance, optimize sales strategies, and improve decision-making through interactive analytics and visual reporting.
